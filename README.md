# つなぐ（紹介アプリ試作）

仕事を探している人を、友達経由で「転職・就職の支援者」に紹介するアプリのクリック可能なプロトタイプ。

## 手元パス

```
/Users/ryoseiworld/dev/2026-09-22-shokai-app/index.html
```

## 開き方

`index.html` をダブルクリックしてブラウザで開くだけ（外部ライブラリ・サーバー不要）。

データはブラウザの localStorage（キー `shokai_v1`）に保存される。初回起動時にサンプル支援者カードが1枚入る。

## 画面構成

- 支援者タブ: 支援者カード一覧、自分のカードを作るフォーム
- 紹介するタブ: 支援者を選んで紹介文を自動生成、コピー／LINEで送る、紹介の記録の状態管理
- 相談するタブ: `?ref=紹介ID` 付きURLで開くと対応する支援者を自動表示
